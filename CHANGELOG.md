# Changelog

## 0.2.0

- Browse and search tracks, albums, playlists, and internet radio stations.
- Play now, next, or last with shuffle options, start Track Radio, and add songs to playlists.
- View, search, jump within, reorder, remove from, and clear the live desktop queue.
- Show Now Playing with fullscreen artwork and mute with volume restore.
- Optionally match the desktop accent in either theme.
- Browsing, playlist actions, radio, and queue management need Feishin 1.16.0 or newer. Earlier versions keep basic playback controls.

## 0.1.1

- Preserve the playback notification icon in release builds.

## 0.1.0

- Initial release with playback controls, saved server profiles, encrypted passwords, reconnects, and Android media controls.
