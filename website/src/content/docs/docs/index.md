Feishin Remote is an Android app that controls a running [Feishin](https://github.com/jeffvli/feishin) desktop player. It connects directly to Feishin's Remote WebSocket API. The audio keeps playing on your computer; your phone becomes the remote.

## Start here

- [Getting started](./getting-started/): enable Remote in Feishin, install the app, and connect.
- [Using the app](./using-the-app/): Now Playing, the library, playlists, radio, the queue, and Android media controls.
- [Troubleshooting](./troubleshooting/): what to check when the app does not connect or a feature is missing.
- [Security](./security/): how credentials are stored and sent.

## Requirements

- An Android phone and a computer running Feishin, on the same network
- Feishin's **Remote control server** enabled and reachable on its port (`4333` by default)
- Feishin 1.16.0 or newer for browsing, playlist actions, radio, and queue management. Earlier versions support basic playback controls.
